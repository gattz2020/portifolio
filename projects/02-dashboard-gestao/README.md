# 📊 Vanguard CRM - Painel Comercial & Gestão Full-Stack

Sistema de dashboard executivo e gestão comercial desenvolvido para pequenas e médias empresas, agências e operações de vendas que precisam centralizar indicadores e esteira de clientes.

---

## 🎯 Recursos e Valor de Negócio

- **Métricas Chave (KPIs)**: Acompanhamento em tempo real de MRR, clientes ativos, taxa de conversão e ticket médio.
- **Gráficos Analíticos Dinâmicos**: Gráfico de linha de crescimento de receita mensal e gráfico doughnut de canais de aquisição com Chart.js.
- **Gestão Completa de Oportunidades**:
  - Busca em tempo real por nome, segmento ou vendedor responsável.
  - Filtro instantâneo por status (*Ativo*, *Negociação*, *Pendente*).
  - Modal para cadastro rápido de novas empresas.
  - Exclusão e persistência dos dados no `localStorage`.
- **Exportação de Relatórios em CSV**: Geração instantânea de planilha compatível com Excel e Google Sheets para o setor financeiro.
- **Responsivo & Tema Escuro/Claro**: Adaptado para acesso em tablets, notebooks e celulares.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5 Semântico, Tailwind CSS.
- **Visualização de Dados**: Chart.js 4.x.
- **Ícones**: Lucide Icons.
- **Armazenamento**: LocalStorage API (com arquitetura pronta para conexão via Fetch/Axios com backend REST em Node.js ou Python/FastAPI).
